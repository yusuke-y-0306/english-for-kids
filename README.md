# English for Kids 🧒📚

子供向け英語学習アプリケーション。

## 概要

- **目的:** 子供たちが楽しく英語を学べるプラットフォーム
- **ステータス:** 開発中 (Vue 3 + Vite)

## 技術スタック

- **フレームワーク:** Vue 3 (Composition API)
- **ビルドツール:** Vite
- **将来拡張:** Vue Router / Pinia / Nuxt.js (必要に応じて)

## 開発予定機能

- [ ] 英単語フラッシュカード (#1)
- [ ] 発音練習・音声認識 (#2)
- [ ] クイズ・ゲーム (#3)
- [ ] 進捗管理 (#4)

チケット管理は GitHub Issues で運用: https://github.com/yusuke-y-0306/english-for-kids/issues

## セットアップ

```bash
npm install
npm run dev
```

## 開発コマンド

| コマンド | 説明 |
|---|---|
| `npm run dev` | 開発サーバー起動 |
| `npm run build` | 本番ビルド |
| `npm run preview` | ビルド結果のプレビュー |
