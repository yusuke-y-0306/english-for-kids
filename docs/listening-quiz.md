# リスニングクイズ（音をきいて絵を選ぶ）— issue #85

未就学児は「文字」で止まる。英語の入口は **音 → 意味（絵）** で、文字は後からでよい。
`/quiz` のレベル一覧の先頭にある「きいて えらぶ」がこのモード。

## 1 ラウンドの流れ

1. 単語の音声が **出題と同時に** 鳴る（事前生成の mp3 / #84）
2. 4 つの **絵（絵文字）** から 1 つ選ぶ
3. 正誤は **音で** 返す（`Great!` / `Try again!` を端末 TTS で）
4. 答え合わせで、正解の絵と単語をもう一度きける

文字（英単語）は **補助**。既定では絵の下に小さく出し、
「もじを かくす」で完全に消せる（設定は localStorage に保存）。
問題文（日本語）も同じトグルで消える。

## 音が鳴らない環境

自動再生ブロックがあるので、**出題時の再生は「ベストエフォート」**。

- 再生できた: そのまま
- ブロックされた / 端末 TTS に逃げた: 「おとが でない ときは、この ボタンを おしてね」を出す
- ミュート中: 「おとが オフ だよ」を出し、`MuteToggle` で解除できる

**どの状態でも「もう いちど きく」ボタンは常に出る**ので、
タップ（＝ユーザー操作）からなら必ず鳴らせる。

## 出題する単語（`src/lib/quiz.ts`）

絵で一意に決まる **具体名詞だけ** を使う。

- 対象カテゴリ: `animals` / `food` / `clothes` / `vehicles` / `home` /
  `school` / `sports` / `body` / `family`
- `pos === "noun"` のみ（`in` `on` `big` `sit` のような語は絵にできない）
- `LISTENING_EXCLUDED_IDS` で、絵が語を表していない単語を外す
  （例: `body/head` の 🗣️ は「話す」に見える、`home/table` の 🍽️ は「食べる」に見える）

ダミーは同じカテゴリ優先で、**語も絵も重複させない**（正解が 2 つに見えるのを防ぐ）。
選び方は `buildListeningQuestions()`、テストは
`tests/unit/quiz-listening.test.mjs` が固定している。

語彙を増やすときは、その単語の `emoji` が「その語を表す絵」になっているかを
`content/vocabulary/*.json` で確認する。抽象語を足すならリスニングには入れない。

## 進捗

- 出題は `wordId` を持つので、**既存のクイズ進捗にそのまま乗る**
  （`POST /api/progress/quiz`、集計・習得度・連続日数は #65 / #76 と同じ）
- レベル ID は `listening`。API のホワイトリストは `quizLevels` が唯一の正
  （`isQuizLevelId()` を増やし忘れない）
- ベストスコアもレベル単位で保存される（既存の `BestScores` がそのまま使える）

## 音声フィードバックについて

ほめことば・はげましのことばは **事前生成していない**（語数が固定でなく、
増やすたびに生成物が増えるため）。`src/lib/audio/play.ts` の `playPraise()` が
端末 TTS（`en-US`, rate 0.9, pitch 1.15）で読む。

- 単語の音声とは排他（鳴っている単語音声を止めてから話す）
- ミュート設定は単語音声と同じ
- 音が鳴らなくても、画面の ⭕ / ❌ と絵で伝わる

将来、声を固定したくなったら `public/audio/phrases/` に mp3 を足し、
`playPraise()` の再生先を差し替えればよい（`audio-check` の対象も足す）。
