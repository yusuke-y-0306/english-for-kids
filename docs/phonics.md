# フォニックス — issue #88

「単語を覚える」の前に要る「文字と音の対応」。26 文字のフォニーム (文字の音) と、
CVC word family (子音+母音+子音) の 40 語で、**読む入口**を作る。

## コンテンツ

| ファイル | 中身 | 語数 |
| --- | --- | --- |
| `content/vocabulary/phonics.json` | アルファベット 26 文字。`pos: "letter"` | 26 |
| `content/vocabulary/phonics-words.json` | 各文字の代表語 3 つ (`a` → apple, ant, ax) | 78 |
| `content/vocabulary/word-family-{at,an,ig,op,ug}.json` | CVC word family。各 8 語 | 40 |

代表語は **`phonics-words` カテゴリの語を頭文字で束ねて**使う (文字 → 語の対応表を
別に持たない)。`en` の 1 文字目が対応する文字になるように作ってある。

### フォニーム音は `tts` で差し替える

TTS は `a` を「エイ」(文字の名前) と読む。フォニックスで欲しいのは /æ/ の音なので、
単語データに `tts` (読み上げ用テキスト) を持たせ、生成時だけ読みを差し替える:

```json
{ "id": "phonics/a", "en": "a", "tts": "ah", "ja": "アの おと", "pos": "letter" }
```

**限界**: これは TTS の近似で、正確なフォニーム音ではない (`r` の /r/ や `x` の /ks/ は
特に苦しい)。将来フォニーム音の録音セットを用意したら、`audio` のパスだけ差し替えれば
画面は変えずに済む (`audioPathForId()` の外側で解決する)。

## モード (画面 `/phonics`)

| モード | 出題 | 選択肢 | 正解が 2 つに見えないための条件 |
| --- | --- | --- | --- |
| おとを きく | フォニーム音 | 文字 4 つ | 同じ文字をダミーにしない |
| さいしょの もじ | 代表語 (絵+音) | 文字 4 つ | 同じ頭文字の語をダミーにしない |
| おなじ おと | word family の見出し (`-at`) | 語 4 つ | 同じ family の語をダミーにしない |

問題づくりは `src/lib/phonics.ts` の純粋関数。**乱数は引数**なので、
`tests/unit/phonics.test.mjs` が並びを固定して境界 (重複・正解 2 つ) を検証する。

### 文字が読めない子向けの約束

- 選択肢の文字は大きく出すが、**音で解ける**ようにしてある (音を聞き直せるボタン)
- 出題文はひらがな。英語の指示文を読ませない
- 正誤のフィードバックは 1 行。間違えても正解を大きく見せるだけで、責めない

## 進捗

回答すると、**選んだ語の `wordId`** を既存のカード API (`POST /api/progress/cards`)
に送る。`phonics/a` や `word-family-at/cat` は `findWordById()` で解決できるので、
進捗画面のカテゴリ別・単語別、ストリークにそのまま反映される。

**未対応**: クイズのラウンド数・正答率には入らない (`isQuizLevelId()` の
ホワイトリストにフォニックスを足していない)。ラウンドとして数えたい場合は、
`quizLevels` に追加するのではなく `/api/progress/quiz` の `level` を広げる設計判断が要る。

## カード・クイズには出さない

`phonics` / `phonics-words` / `word-family-*` は **練習専用カテゴリ**として
`words.ts` の `playCategories` から外してある (カード一覧・クイズ・きょうのカード)。
`categories` には残すので、進捗と発音の ID 解決は今までどおり動く。

## 音声

- 26 フォニーム + 78 代表語 + 40 CVC = 144 ファイル (`public/audio/words/**`)
- 生成は既存の `npm run audio:generate` (TTS テキストだけ `tts` を使う)
- 合計予算は 344 語で ~3.6MB になったため 5MB に引き上げ (`audio-assets.ts`)

### `x` だけは語尾で教える

`x` は英語の語頭にほぼ現れないので、代表語は **box / mix / wax** と語尾の音で置いた。
このため「代表語の頭文字 = 文字」の対応から `x` だけ外れる (単体テストで明示)。
「さいしょの もじ」モードに `x` の問題は出ない。
